# 交付审阅

本次将虚构任务模拟器替换为用户指定闭环的程序模块。提交代码不是部署批准，也不是资金方案批准。

## 验证记录

- Python 规则/SQL 测试：24 项通过，覆盖费用未知、并发预算、暂停、去重、本金与收入分离、市场估值。
- 执行器测试：12 项通过，覆盖固定操作完整顺序、广播超时后重启、暂停、失败 Gas 记账、进入过期撤销、合约变化阻断。使用公开测试私钥和受控 RPC，没有实际资金。
- Cloudflare 官方本地 Python 运行时：入口、鉴权、跨站请求拒绝、D1、定时事件和暂停已检查。Merkl 官方 API 实际返回 10 个候选；候选不是投资推荐。
- 独立签名 Worker 已在真实本地 workerd / SQLite Durable Object 中验证机器密钥不能批准/恢复，以及错误密钥被拒绝；主 Worker 的暂停请求通过 Service Binding 到达签名 Worker。
- 两个 Worker 均完成本地 dry-run 打包，没有向云端部署。
- Binance 页面本次不可直接读取，显示 binance_listing_unreadable。不能声称其数据采集或自动参与已可靠跑通。
- 没有真实模型请求、通知送达或链上广播；没有实盘验证。

## 优先检查

1. GOAL.md：两类候选，每个资金方案先批准，全部费用进入核算和复盘。
2. policy.py / executor/policy.js：权限、金额、期限与固定适配器范围。
3. executor/engine.js：模拟、持久化后广播、回执、停止与残余授权。
4. finance.py：预计、实际数量、市场估值、风险预留的区别。

## 本次模块整理

- economics.py、ledger.py、valuation.py 合并为 finance.py，仍然分开记录预计收益、实际收支和市场估值。
- analyst.py、review.py 合并为 ai.py；复盘所需账目由总调度准备，复盘结果由总调度保存。
- finance.py 不导入模型、钱包或网络客户端；需要报价时使用总调度传入的只读查询。
- policy.py 不再依赖钱包执行模块；只接收只读预览能力，不能在制作方案时执行交易。
- 旧五个文件已删除；API、数据库和签名权限没有扩大。Python 模块依赖无循环。
