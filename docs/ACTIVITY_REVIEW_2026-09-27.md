可核对的当期例子：[Morpho OETH/USDC 借款奖励](https://api.merkl.xyz/v4/opportunities/13910696446007033969)要求借款；[World Chain Re7 USDC 金库](https://api.merkl.xyz/v4/opportunities/11217817339280669184)不在现有执行器支持链内。这里记录排除原因，不推荐参与，也不把资料不足解释为活动本身不安全。

- 38 项 Python 规则/数据库测试通过，其中真实资料回放只模拟判断，不实际参与。

- Cloudflare 官方本地运行时验证通过：鉴权、D1 迁移、暂停、定时入口、真实公共 API 读取与 10 个候选筛选。
- 模型角色、费用、超时和回答格式使用模拟 API 验证；没有真实模型质量评测或盈利结论。
- 云端部署、真实资金参与、API 付费及实际推送均未进行。

## 本轮程序变化

1. 固定规则先排除过期、缺日期、借款、不支持的链/操作和奖励适配；通过只允许继续研究，不等于参与获批。
2. 页面显示筛选原因和参考成本测算。缺少 Gas、退出等费用时净收益保持未知。参考本金不是资金授权。
3. 普通分析和复盘可使用不同模型、价格及单次费用上限，共享总预算和每日次数上限；AI 复盘默认关闭。
4. 模型记录保存输入快照、规则版本、结果、用量和价格配置，供以后人工比较。未实现付费双跑实验，也不会根据一次结果自动切换模型。
5. 超时保留费用预留，不自动重试；结构错误的回答不能使用，已产生的用量仍记账。

## 上线前仍缺什么

合格当期活动及其规则证据、用户资格、合法可用的模型服务、经过审阅的活动合约配置、独立实验钱包，以及每个具体资金方案的批准。当前执行器仅支持核查过的 ERC4626 金库和本金同币奖励；不能为了凑活动把 MORPHO/PIKU 等奖励直接当成稳定币，或自动添加兑换权限。

程序不会以“开始自动运行”为理由强行找到一个投资对象。下一轮应先解决可读来源和真实候选匹配，再决定是否需要增加受限的奖励兑换适配。
