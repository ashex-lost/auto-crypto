# auto-crypto

空投自动参与实验：云端运行、确定性执行、独立资金权限。

## 当前状态
这是**模拟执行基础版本**，不是已上线的赚钱机器人。
- SQLite 保存任务、模拟费用及工作进程心跳。
- 同一任务 ID 不会重复计费；不同内容复用 ID 会被拒绝。
- 原子检查单任务及累计模拟费用上限。
- 支持暂停文件、重启恢复、JSON 状态输出。
- 不包含活动发现、模型调用、钱包签名、实盘交易或通知。
- 模拟结果不代表空投资格或投资收益。不可将它用于实盘风险控制。

## 本地验证
需要 Python 3.9+，无第三方依赖。
```sh
python3 -m unittest discover -s tests -v
python3 worker.py enqueue --id demo-1 --cost-cents 5
python3 worker.py once
python3 worker.py status
```
金额单位为模拟美元分，仅用于验证预算机制，不是链上代币单位。
任务在本机创建时默认写入 data/state.db；不要提交数据库。

## 云端部署
仓库包含 Render Blueprint，但**尚未部署或验证云端运行**。
1. 在 Render 创建账户并连接这个仓库。
2. 选择 New → Blueprint，选择仓库，检查 render.yaml。
3. 确认付费 worker 和磁盘费用后才创建服务。
4. 等待构建测试通过、日志出现心跳。
5. 在 Render Shell 使用相同 DATA_DIR 创建模拟任务，检查 status。
6. 重启服务并确认任务没有重复执行、历史仍存在。

本版本没有公网控制面板。空队列会保持等待，不会自行虚构活动或奖励。
暂停：在持久数据目录创建 PAUSED 文件；恢复：删除该文件。
生产密钥不得写入仓库、聊天、日志或此 worker 环境。
