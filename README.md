# auto-crypto

加密资产空投实验项目。当前仅有本地 Python 模拟执行器，没有云端服务或实盘交易。

## 当前功能
- SQLite 保存模拟任务、费用和心跳
- 相同任务 ID 去重，冲突内容拒绝
- 单任务和累计模拟费用限额
- 暂停、重启恢复、JSON 状态
- 5 项本地测试已通过

尚未实现活动发现、资格判断、AI 调用、通知、钱包签名或真实交易。模拟结果不代表空投资格或收益。

## 本地运行
需要 Python 3.9+，无第三方依赖。

```sh
python3 -m unittest discover -s tests -v
python3 worker.py enqueue --id demo-1 --cost-cents 5
python3 worker.py once
python3 worker.py status
```

模拟费用单位为美元分，用于检查程序逻辑，不代表链上代币。数据默认写入 `data/state.db`，不得提交。

## 云端方案

选择 [Cloudflare Workers Free](https://developers.cloudflare.com/workers/platform/pricing/) 作为首个无绑卡部署目标。它提供定时触发和有限免费资源；D1 可保存任务状态。当前 Python 程序使用本地 SQLite 文件，**不能直接当作 Cloudflare Worker 部署**。必须另行编写 Workers 入口、D1 数据层，并在上线前完成云端测试。旧 Render 付费部署配置已移除。

免费资源的上限及定时触发的时效性需要用实际活动验证。即使程序部署成功，也不等于能自动参加任何活动。

## 实盘前必须完成
1. 核实所在地、账户及目标活动的参与资格与自动化规则。
2. 选择具体活动，记录官方规则、成本、奖励不确定性和退出条件。
3. 接入只读数据、通知与账本，对模拟流程端到端验证。
4. 将签名能力与 AI 隔离；用独立钱包和可强制执行的金额、合约、频率限制。
5. 取得具体策略与资金范围的一次性授权，再接入真实交易。
6. 超时先查询链上或平台状态，再决定是否重试；所有成本和失败都入账。

私钥、助记词、API 密钥和资金信息不得写入公开仓库。模型 API 与托管服务的地区资格须分别核实；云端位置不能代替用户或账户资格。
